# Sumber logo brand untuk prototipe Orka

Diunduh 31 Oktober 2026. Logo dipakai sebagai pengganti visual sementara pada data ormawa fiktif, sesuai permintaan pemilik produk. Nama dan identitas data ormawa tetap fiktif; tidak ada klaim organisasi kampus tersebut milik atau berafiliasi dengan brand.

| Ormawa contoh | Logo | Sumber aset |
| --- | --- | --- |
| BEM Contoh | Google | https://github.com/devicons/devicon/blob/master/icons/google/google-original.svg |
| Hima A Contoh | Slack | https://github.com/devicons/devicon/blob/master/icons/slack/slack-original.svg |
| Hima B Contoh | Figma | https://github.com/devicons/devicon/blob/master/icons/figma/figma-original.svg |
| UKM Olahraga Contoh | Discord | https://cdn.prod.website-files.com/6257adef93867e50d84d30e2/66e3d80db9971f10a9757c99_Symbol.svg |
| UKM Seni Contoh | GitHub | https://github.com/devicons/devicon/blob/master/icons/github/github-original.svg |

Google/Slack/Figma/GitHub memakai SVG dari koleksi Devicon; salinan lisensi koleksi ada di DEVICON-LICENSE.txt. Merek/logo tetap milik pemegang masing-masing. Versi ikon ini bukan klaim aset brand paling baru. Discord diambil melalui tautan simbol pada halaman brand resminya.

Panduan brand yang ditinjau:

- https://about.google/intl/enUS/brand-resource-center/
- https://app.slack.com/media-kit
- https://www.figma.com/using-the-figma-brand/
- https://discord.com/branding

Aset disimpan lokal, bukan hotlink. Warna dan bentuk internal SVG tidak diubah; wadah putih menyediakan ruang di sekitar simbol. Fallback tetap inisial ormawa. SVG buatan sebelumnya dipertahankan sebagai riwayat aset prototipe.
